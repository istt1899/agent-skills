# Перенос и установка навыка

Этот каталог — полный переносимый пакет навыка `create-technopack-presentations`. Вместе с `SKILL.md` передаются `references/`, `scripts/`, `assets/`, `agents/` и контрольный `MANIFEST.sha256`. Все относительные ссылки в Markdown остаются внутри пакета; путь к исходному компьютеру не нужен.

## Установка агентом

1. Получи репозиторий `https://github.com/istt1899/agent-skills`.
2. Установи **весь** каталог `skills/create-technopack-presentations/` в каталог навыков своей агентной среды. Один `SKILL.md` без соседних файлов недостаточен. Если среда поддерживает Skills CLI, можно использовать `npx skills add istt1899/agent-skills --skill create-technopack-presentations`.
3. Проверь целостность из установленного каталога: `sha256sum -c MANIFEST.sha256`. На Windows без `sha256sum` сравни SHA-256 каждого файла с перечнем в manifest.
4. Зарегистрируй навык в механизме обнаружения своей агентной среды, прочитай `SKILL.md` и обязательные для конкретной задачи файлы `references/`. Подтверди, что навык виден агенту и все относительные ссылки открываются.
5. Для статической проверки HTML нужен Node.js. Для браузерных проверок нужен установленный Playwright с Chromium и WebKit; путь к модулю можно передать через `PLAYWRIGHT_MODULE`. Проверяй фактическую доступность, не объявляй тест пройденным по одной установке пакета.

Интеграции Technopack, Search Tpak, MarkInfo, 1С, Taobao и Concave LAB используются только при наличии соответствующих сервисов и прав в среде получателя. Пакет не содержит ключей и не устанавливает эти сервисы. Отсутствующий маршрут доставки, источник данных или проверку отмечай как ограничение; не имитируй квитанцию. Генератор ссылок Taobao и его стандарт включены для автономной работы с подтверждённым ID товара.

## Готовый запрос агенту

> Установи навык `create-technopack-presentations` из `https://github.com/istt1899/agent-skills/tree/main/skills/create-technopack-presentations`. Скопируй каталог целиком, проверь `MANIFEST.sha256`, зарегистрируй навык в своей среде, прочитай `SKILL.md` и его обязательные references. Сообщи путь установки, результат проверки целостности и какие внешние интеграции доступны. Не запрашивай и не выводи секреты.
