# Ссылки в презентациях Taobao Market

Решение владельца 29.10.2026: при открытии презентации на iPhone переход к товару должен вести в приложение Taobao.

- Для каждой карточки используй точный ID предложения и `bot.taobao.presentation_links.render_product_links`: первая статическая ссылка открывает `taobao://item.taobao.com/item.htm?id=<ID>`, рядом остаётся отдельная HTTPS-ссылка исходной карточки для браузера.
- Два адреса должны вести к одному ID. Неподдерживаемый адрес, отсутствующий или несовпадающий ID нельзя превращать в ссылку на предположительный товар.
- Ссылки доступны без JavaScript. Браузерный источник открывается в новой вкладке; ссылка в приложение вызывается непосредственно нажатием без автоматического таймера, редиректа или обещания, что приложение установлено.
- Проверяй на каждой выдаче ссылки и идентичность ID, клавиатуру и поведение без JavaScript, рендер на мобильном WebKit и desktop. Фактическое открытие конкретной карточки проверяй отдельно на iPhone с установленным Taobao из конечного HTML и встроенного просмотрщика Telegram; эмуляция и наличие href не заменяют такую проверку.
- До физической проверки схема приложения считается кандидатом: её формат известен по исторической публичной документации, но совместимость с текущей версией приложения и настройки устройства не подтверждена. При невозможности проверки сохраняй браузерную ссылку и явно указывай ограничение.

## Общий расчёт китайских подборок · 30.10.2026

Единый HTML для Taobao, Tmall, Xiaomi Youpin и следующих площадок строится на одном замороженном снимке и одной модели стоимости. Адаптер платформы сохраняет upstream ID, точную модель и суффикс, оригинал с полным русским переводом, главные характеристики, цену единицы, доступность, вес и время наблюдения; отсутствующее поле не заменяется нулём или догадкой.

- Каждая карточка содержит галочку выбора, количество, цену товара, логистическую базу, карго, приблизительный итог CNY и RUB, ссылку на первоисточник и ограничения. Итог формируется только по выбранным строкам, полный русский список копируется локально.
- Курс — только `bot.taobao.rate_bestchange`: RUB→USDT→CNY WeChat/Alipay, дата и stale-флаг видны. Товар и логистика считаются отдельно; итог не называется ценой магазина или окончательным тарифом.
- Общий норматив карго: 3,5 USDT/кг. Для дисков действует особое правило владельца: +5 кг на диск и 50 USD упаковки на комплект из четырёх. На другие категории эти добавки не переносятся.
- Для Xiaomi Youpin логистическая база — `postWeight` выбранного `pid`. Пока единица и состав брутто не подтверждены документом, расчёт помечается сценарием, а одинаковое значение у разных товаров — сигнал обязательной проверки, не основание для ложной точности.
- Если веса нет, показывается «нужен вес», а не нулевая доставка. Таможня и НДС, комиссия посредника, довоз по России, страхование и негабарит исключаются до отдельного подтверждения; наличие и доставка по адресу владельца проверяются отдельно.
- Реализация эталона и симуляция A/B/C: `specs/xiaomi-youpin-20261030/`. Обязательны click-аудит N/N, 320/390/1280, Chromium/WebKit, offline/no-JS, полная печать и provenance.

Источники: [Apple: диагностика Universal Links](https://developer.apple.com/documentation/technotes/tn3155-debugging-universal-links); [пример схемы Taobao для карточки товара](https://www.v2ex.com/t/65843).
