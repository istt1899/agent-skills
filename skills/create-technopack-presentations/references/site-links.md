# Постоянные ссылки сайтов и презентаций

По правилу владельца от 21 сентября 2026 года презентацию владельцу сопровождай индивидуальной постоянной ссылкой на её веб-версию без пароля; дублируй её в подписи и HTML, проверяя открытие без авторизации. Уточнение 01.10.2026: для всех клиентских КП и документов обязательна отдельная уникальная ссылка только на один документ со сроком календарный месяц, серверным отзывом и без доступа к кабинету или чужим документам; постоянную ссылку владельца клиенту не выдавай, ранее отправленный адрес мигрируй с сохранением того же ограничения и без продления.

Для ссылок на собственные сайты используй короткий адрес на домене соответствующего проекта: `https://<домен>/s/<код>`. Перед выдачей создай запись в постоянном хранилище и проверь весь переход до нужной страницы; сокращение строки без записи не является ссылкой.

Код постоянной ссылки владельца сохраняет назначение без срока истечения; клиентский код сохраняет назначение до истечения срока и никогда не переиспользуется для другого объекта. В адресе нет персональных данных, токенов и названий скрытых поставщиков. Резервная копия сайта включает хранилище ссылок. Разрешены только публичные страницы проекта; произвольные внешние переадресации запрещены.

У каждой позиции презентации есть обычная HTML-ссылка на её карточку. Для разноширокого комплекта нужны отдельные ссылки передней и задней оси. Прежде чем создать ссылку, сохрани карточку; если точный товар не установлен, подпиши переход «Найти на сайте» и передай подтверждённые фильтры, не выдавая поиск за карточку.

Файл презентации остаётся автономным: фото, текст и характеристики доступны без сети и JavaScript, переход на сайт добровольный. Цена в файле — снимок на указанную дату, на сайте — результат последней проверки. Исчезнувший товар сохраняет страницу со статусом отсутствия; сбой API не означает нулевой остаток.

В Concave LAB используется `https://concavelab.ru/s/<код>` и единый модуль коротких ссылок проекта; карточки публикует его штатный каталог, постоянное соответствие хранит `web_short_links` в общей БД гаража. Не создавай параллельный сокращатель в отдельном генераторе. Новые и пересобранные файлы проверяй HTTP-запросами по всем уникальным ссылкам; уже отправленные вложения меняются только при пересборке и повторной доставке.
