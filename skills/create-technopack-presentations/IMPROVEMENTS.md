# Журнал улучшений стандарта презентаций

## Финансовые графики и таблицы · 30.10.2026

По решению владельца все графики и таблицы показывают измеряемый показатель, единицы и масштаб, период или дату среза, подписи, источник и существенные допущения; финансовая аналитика дополнительно показывает выручку, состав затрат, правильно названный результат и маржинальность; неизвестные данные не принимаются за ноль. Изменение уточняет содержание и приёмку, не изменяя текущее поведение starter или генераторов.


## presentations-v2 · 29.10.2026

Переработан каждый блок стандарта по аудиту и разбору пяти самых популярных open-source проектов презентаций (reveal.js, Slidev, impress.js, Marp, Spectacle) и популярных скиллов skills.sh.

1. Ответ первым экраном (BLUF): тема, вывод, цифры, действие за 10 секунд — раньше открытие было только историей.
2. Кликабельная карта разделов + возврат «К содержанию» из каждого раздела — раньше только линейная прокрутка.
3. Прямые якоря на каждый раздел — можно отправить ссылку на конкретный ответ.
4. Один источник содержания → HTML и печать — цифры больше не расходятся между местами вёрстки.
5. Визуальная грамматика: форма данных выбирается по вопросу читателя, диаграммы — inline-SVG, читаемые на 390 px.
6. Основной путь читается без раскрытия спойлеров; глубина — в `<details>` и досье.
7. PDF проверяется глазами целиком, включая печатную обложку (инцидент 28.10.2026).
8. Новый раздел «Симуляции»: нет мёртвых кнопок, состояния норма/пусто/ошибка/ожидание, постоянный возврат «Домой», прямые ссылки на состояния, проверка Chromium+WebKit.
9. Простой язык: термины объясняются, числа с единицами, абзацы до 4 строк.
10. Приёмка агентом: чек-лист v2 + JSON-отчёт + `standard: presentations-v2` в provenance; поведение меняется одновременно в SKILL.md, reference, starter и генераторе.

Файлы: новый `references/navigation-and-simulations.md`; правки `SKILL.md` (обязательное чтение v2 и расширенная приёмка).
